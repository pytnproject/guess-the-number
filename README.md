# Guess the Number Game

A simple command-line guessing game written in Python. The computer picks a random number between 1 and 100, and the player tries to guess it.

## Features
- **Two game modes:** Unlimited attempts or limited to 10 attempts.
- **Input validation:** Handles invalid inputs (text instead of numbers).
- **Attempt counter:** Tracks how many attempts the player used.
- **Replayable:** Allows the player to start a new game after finishing.

## How to Run
1. Ensure you have Python 3.x installed.
2. Clone the repository:
   ```bash
   git clone https://github.com/pytnproject/guess-the-number.git

3. Navigate to the project folder:
   ```
   cd guess-the-number
   ```
4. Run the script:
   ```
   python script.py
   ```
